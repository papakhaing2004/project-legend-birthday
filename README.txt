PROJECT LEGEND — BIRTHDAY EDITION
A static birthday surprise website built with HTML, CSS and JavaScript.

FILES
- index.html  : page structure and content
- style.css   : cinematic styling and responsive layout
- script.js   : interactions and personalization settings
- assets/     : put the streamer's photo here

QUICK SETUP ON WINDOWS / ASUS VIVOBOOK
1. Download and extract Project_LEGEND_Birthday_Website.zip.
2. Open the extracted project_legend folder.
3. Copy his photo into the assets folder and rename it exactly: streamer.jpg
   Supported common formats include JPG/JPEG and PNG. If using PNG, either convert it to JPG
   and name it streamer.jpg, or change the src in index.html to assets/streamer.png.
4. Open script.js in VS Code or Notepad.
5. Near the top, replace YOUR STREAMER in STREAMER_NAME with his nickname.
6. Edit BIRTHDAY_MESSAGE to make it sound like you. Keep the quotation marks around the text.
7. Save all files.
8. Double-click index.html to preview it in Chrome or Edge. Internet is needed only for the optional Google font;
   the website itself works locally without a server.

SHARE IT ONLINE FOR FREE WITH GITHUB PAGES
1. Sign in or create an account at https://github.com/.
2. Create a new repository, for example: project-legend-birthday.
   If you want the site public, choose Public. Remember that public repository source files can be viewed by others.
3. Upload the contents of this folder (index.html, style.css, script.js, README.txt, and the assets folder with the photo).
   Ensure index.html is at the repository root, not inside another nested folder.
4. In the repository, open Settings → Pages.
5. Under Build and deployment / Source, choose “Deploy from a branch”. Choose the main branch and /(root), then Save.
6. Wait a few minutes and revisit the Pages settings for the published website link.
7. Open the published link on your phone to test it, then send it to him with a short message.

PRIVACY NOTE
A GitHub Pages site is public to anyone with the link, and the repository source may be public too.
Only use a photo he is comfortable having shared online. Do not put private information, passwords,
phone numbers, addresses, or private conversations in the website. If you do not want the photo public,
share the website folder privately instead, or use a host with appropriate access controls.

PERSONALIZATION
- Change STREAMER_NAME and BIRTHDAY_MESSAGE in script.js.
- To change visible headings, edit the text in index.html.
- To change colors, edit the variables at the top of style.css.

The website uses original superhero-inspired visuals and does not include official Marvel/DC logos or characters.
